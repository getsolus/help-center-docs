# Plasma System Monitor

[Plasma System Monitor][1], also known as KSysGuard or KDE System Guard, is designed to make simple process control available to a user without needing to do any special setup.

## Installation

Plasma System Monitor is usually installed as part of the KDE Plasma Desktop environment, but can be installed from the Software Center or via terminal:

```bash
sudo eopkg it plasma-systemmonitor
```

## Usage

KSysGuard [User’s Guide][2] or the KDE UserBase Wiki (open khelp on your Plasma Desktop).
